Use a Limited Access key from Torn → Settings → API Keys, so the game can read your equipped weapons and armour.

What happens with my key?

Your key stays in your browser and is only sent to Torn's own API (api.torn.com). The game reads your name, ID, level, profile picture and equipped items. Nothing goes to any other server. The key is saved on this device so you don't have to type it again; tap "Log out" to remove it.
