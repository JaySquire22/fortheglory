Use a Limited Access key (Torn → Settings → API Keys) so the game can read your equipped weapons and armour.

What happens with my key?

Your key stays in your browser and is only sent to Torn's own API (api.torn.com). The game reads your name, ID, level, life, profile picture and equipped items. Nothing goes to any other server. The key is saved on this device; "Log out" removes it.
